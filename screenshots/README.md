## 🎨 Wytyczne

- **Format:** PNG lub WebP
- **Rozdzielczość:** 1920x1080 (desktop), 375x812 (mobile)
- **Waga:** <500KB per screenshot
- **Nazewnictwo:** opisowe, kebab-case
- **Brak:** wrażliwych danych, osobistych informacji
